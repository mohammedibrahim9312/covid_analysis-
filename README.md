

# 🦠 COVID-19 Data Analysis Project

## 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** and visualization on global COVID-19 data to uncover trends in infections, recoveries, and deaths across different regions. The goal is to extract meaningful insights and understand how the pandemic evolved over time using data science techniques.

---

## 🎯 Objectives

* Clean and preprocess COVID-19 datasets
* Analyze global and regional trends of COVID-19 cases
* Visualize infection, recovery, and death rates
* Identify patterns and correlations in the data
* Generate insights to support data-driven understanding of the pandemic

---

## 📊 Dataset

The dataset used in this project typically includes:

* Date-wise confirmed cases
* Death cases
* Recovered cases
* Country/Region information

> Data source: Public COVID-19 datasets (e.g., Johns Hopkins University / Kaggle datasets)
